# PWCC

Codul sursă pentru seminarul PWCC. Fiecare director conține un proiect, cu instrucțiunile în propriul README.

| Director | Proiect |
| --- | --- |
| [`random-forest-wasm`](random-forest-wasm/) | Random Forest scris în C++, compilat în WebAssembly și rulat în browser, pe un fișier CSV ales de utilizator |
| [`agentic-workflow`](agentic-workflow/) | Dezvoltarea asistată de coding agents: opt skill-uri pentru fazele unui task, de la scoping la pull request, documentele proiectului și aplicația de exemplu Task API, un backend Node.js și Express |
